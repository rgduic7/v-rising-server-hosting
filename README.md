## 三条路线，钱花在哪不一样

### 本地自建：不花钱，花时间

在自己电脑或家里的旧机器上跑 dedicated server，不需要付服务器租金。代价是四件事：家庭宽带多数没有固定公网 IP、部分运营商不给做端口转发、机器得一直开着、家里网络晚高峰会抖。

还有一层成本是排查。Steam 社区有个帖子，玩家启动服务器后，游戏内和 Steam 服务器浏览器里都看不到自己的服，日志文件 `service_log.txt` 反复写 `Failed to load Steam Service (GLE 126)`。他已经在防火墙放行了 UDP 9876、9877、27015、27016，在 Windows Server Defender 里放行了应用和端口，甚至把 Defender 整个关掉；同一台机器上还跑着两个《英灵神殿》实例，一切正常。帖子发出来之后没有回复。这里无法断定原因（那几个端口也不是官方公布的端口清单），这正说明自建路线真正的成本在于排查时间，而且社区里可能没人接手你的问题。

### 云服务器：付钱换掉公网 IP 和端口转发

云服务器把上面四件事一次解决：每台实例独立公网 IP、防火墙在控制台点几下就开、机器 7×24 在线、走机房网络。下单到能连通常几分钟。对《夜族崛起》这种要长期挂存档的游戏，这四条比省下的几十块钱重要。

雨云这边还有两个具体的好处：面板里能直接做 CPU 升降级，人多了加钱升配就行，不用重装；7 天内无理由退订，每个账号限 3 次，第一次开服试错成本基本为零。

### 虚拟局域网：朋友不想买服务器时的办法

蒲公英这类工具的思路是用 SD-WAN 把异地设备组成一个虚拟局域网，游戏把连接识别成局域网，发起方建房间拿到房间号，朋友输房间号加入，再在游戏里用虚拟 IP 直连，数据不经游戏服务器中转。客户端支持 Windows、Android、iOS，macOS 暂不支持；路由器方案里内嵌了迅游加速器，新注册用户可免费领 10 天 SVIP，每台设备限 1 次，接入路由器的 Switch、PS5、PC 都走加速通道。客户端联机功能有免费额度和服务等级，具体额度得看官方计费说明。

这些是厂商自己的说法。这条路适合“每周六晚上凑两小时”的玩法，不适合当长期存档的主服：发起人的机器一关，服就没了。

## 《夜族崛起》的存档要用几个月，不是一晚上

城堡也不是摆设。城堡之心能升级，升到 3 级解锁“莫尔蒂姆之眼”配方，摆出来才能看到裂隙入侵的位置和刷新时间；裂隙事件要按中央祭坛上方的黑线指示跑到对应位置清怪、打碎水晶，两个位置做完再回祭坛打血魂 BOSS 才算关闭。传送门走到附近才解锁，多人服里基本当集合点用。

**4 个人到底要多大内存？**
4G 起。2核4G 的 30 元面板机是这一档里最便宜的合理选择，先跑一周看占用，不够再升。

**服务器开着，朋友能轮流上线吗？**
能。存档在服务器上，谁上线都不影响别人，不开机的人不会拖慢服。需要重启维护时在面板里操作，玩家会掉线重连。

**存档怎么备份？**
雨云游戏云面板自带自动备份，也能自己在面板里打快照。想额外留一份就定期下载存档目录，具体路径按你部署的服务端结构走，别照抄别人的命令。

**PS5、Xbox 能连吗？**
主机端一般不能像 PC 那样输入 IP 直连，只能从服务器列表进，这在同类游戏的开服文档里是明写的。《夜族崛起》主机端具体怎么连，下单前先在游戏里确认一次，别默认买个服务器主机朋友就能进来。

**能退吗？**
7 天无理由退订，每个账号限 3 次。第一次开服不确定配置够不够，退订条款比价格更值得先看一眼。
